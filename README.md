Project: Rename Files (Python)

Description:
This script renames all files in a folder with a new prefix and sequential numbers.

How to use:
1. Put this script in Pydroid 3 or Python.
2. Run the script.
3. Enter the folder path.
4. Enter new prefix (example: image).
5. Enter start number (example: 1).
6. Optionally enter extension (leave blank to keep original).

Example output:
image_001.jpg
image_002.jpg
image_003.jpg
